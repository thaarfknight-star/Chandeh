# نرخ‌روز (NerkhRooz)

اپلیکیشن اندرویدی قیمت لحظه‌ای دلار، ارز، سکه و طلا — مشابه اپ **Chand** نسخه‌ی iOS
(https://apps.apple.com/us/app/chand/id1524200188)، ولی فارسی و راست‌چین.

## امکانات نسخه‌ی ۱٫۰

- **لیست زنده‌ی قیمت‌ها** در سه بخش ارزها (۱۰ ارز بازار آزاد)، طلا و سکه (۸ قلم)
- نمایش قیمت به **تومان** با اعداد فارسی، مبلغ و درصد تغییر روزانه (سبز/قرمز ▲▼) و ساعت به‌روزرسانی
- **مبدل ارز**: تبدیل هر نماد به هر نماد دیگر با قیمت روز
- تم تیره، رابط کاملاً فارسی و راست‌چین
- دکمه‌ی به‌روزرسانی دستی + تلاش مجدد هنگام خطا

## منبع داده

وب‌سرویس عمومی **TGJU** — بدون نیاز به ثبت‌نام و API Key:

```
http://platform.tgju.org/fa/api/webservice-snippet/?token=webservice&items=...&opts=diff,time
```

قیمت‌ها به **ریال** برمی‌گردند و در اپ به تومان تبدیل می‌شوند (÷۱۰).
این وب‌سرویس غیررسمی است؛ پارسر اپ دفاعی نوشته شده (به ترتیب سطرها اعتماد می‌کند نه به نام‌ها)
و اگر ساختار پاسخ عوض شود، خطای خوانا با دکمه‌ی تلاش دوباره نمایش داده می‌شود.

## بیلد

### با Android Studio
پروژه را باز کنید و Run بزنید. (minSdk 26)

### با GitHub Actions
هر پوش به شاخه‌ی `main` به‌صورت خودکار APK دیباگ می‌سازد؛
فایل را از تب Actions همان ران، بخش Artifacts با نام **NerkhRooz-debug-apk** دانلود کنید.

## ساختار پروژه

```
app/src/main/java/com/nerkhrooz/app/
├── MainActivity.kt            # اکتیویتی اصلی + ناوبری پایین (قیمت‌ها / تبدیل)
├── data/
│   ├── Symbols.kt             # لیست نمادها و کدهای TGJU
│   ├── TgjuService.kt         # اینترفیس Retrofit
│   └── PriceRepository.kt     # دریافت + پارس پاسخ
├── ui/
│   ├── PricesViewModel.kt
│   ├── theme/Theme.kt         # تم تیره
│   └── screens/
│       ├── PriceListScreen.kt
│       └── ConverterScreen.kt
└── util/FaNumbers.kt          # اعداد فارسی و جداکننده‌ی هزارگان
```

## نقشه‌ی راه
