# NerkhCheck

اپلیکیشن اندرویدی قیمت لحظه‌ای دلار، ارز، سکه و طلا — مشابه اپ **Chand** نسخه‌ی iOS
(https://apps.apple.com/us/app/chand/id1524200188)، ولی فارسی و راست‌چین.

## امکانات نسخه‌ی ۱٫۰٫۱

- **لیست زنده‌ی قیمت‌ها** در چهار بخش: ارزها (۱۰ ارز بازار آزاد)، طلا (۳ قلم)، سکه (۵ قلم) و **ارز دیجیتال** (بیت‌کوین، اتریوم، تتر)
- نمایش قیمت به **تومان** با اعداد فارسی، مبلغ و درصد تغییر روزانه (سبز/قرمز ▲▼) و ساعت به‌روزرسانی
- **قیمت‌گذاری چندمنبعی کامل**: دریافت موازی از ۶ منبع (سرورهای ایران در اولویت) —
  روی اینترنت ملی هم قیمت‌ها زنده می‌مانند
- **سازگار با اینترنت ملی**: منابع داخلی (سرور ایران) در اولویت‌اند؛ طلا، بخشی از سکه‌ها
  و ارزهای دیجیتال بدون نیاز به کلید، زنده دریافت می‌شوند
- **کلید BRS (اختیاری)**: با ثبت کلید رایگان BRS در تنظیمات، دلار و همه‌ی ارزها هم روی اینترنت ملی زنده می‌شوند
- **کش هوشمند**: آخرین قیمت‌های موفق ذخیره می‌شوند؛ وقتی منبعی در دسترس نیست، قیمت ذخیره‌شده با برچسب «ذخیره‌شده» نمایش داده می‌شود و اپ هیچ‌وقت خالی نمی‌ماند
- **مبدل ارز**: تبدیل هر نماد (شامل رمزارزها) به هر نماد دیگر با قیمت روز + «تومان ایران» به‌عنوان واحد پایه
- **صفحه‌ی تنظیمات**: ۱۲ تم ترکیب‌رنگی (شفق قطبی، آتشفشان، کهکشان، ساحل، جنگل، نئون، طلایی، اقیانوس، زرشکی، سلطنتی، ساکورا، گرافیتی)، بخش داده‌ها و اینترنت ملی (کلید BRS)، نسخه‌ی برنامه، لینک گیت‌هاب و تلگرام پشتیبانی
- **ویجت صفحه‌ی اصلی**: دلار، طلای ۱۸ عیار و سکه‌ی امامی با دکمه‌ی تازه‌سازی
- تم تیره، رابط کاملاً فارسی و راست‌چین، نمایش تمام‌صفحه (edge-to-edge)
- دکمه‌ی به‌روزرسانی دستی + تلاش مجدد هنگام خطا
- **آلارم آپدیت درون‌برنامه‌ای**: روزی یک‌بار آخرین ریلیز گیت‌هاب بررسی می‌شود؛ اگر نسخه‌ی
  جدیدی منتشر شده باشد، داخل خود برنامه اطلاع‌رسانی می‌شود (با دکمه‌ی «مشاهده و دانلود»)
- **خطای تشخیصی**: اگر دریافت قیمت‌ها ممکن نشود، علت خرابی هر منبع (تایم‌اوت، عدم دسترسی
  به سرور، خطای ۴۰۴ و...) در پیام خطا نمایش داده می‌شود تا مشکل سریع پیدا شود
- رفع ناخوانا بودن متن‌های صفحه‌ی تنظیمات روی تم تیره
- رفع باگ نخ اصلی: همه‌ی درخواست‌های شبکه روی Dispatchers.IO اجرا می‌شوند
  (قبلاً فراخوانی از viewModelScope باعث NetworkOnMainThreadException و خالی ماندن
  صفحه‌ی قیمت‌ها می‌شد)

## منبع داده

دریافت از چند منبع به‌صورت موازی، با ادغام بر اساس اولویت (برای هر نماد، اولین منبع موفق؛ منابع داخلی اول):

۱. **BRS API** — سرور ایران، ارز و طلا؛ فقط وقتی کلید در تنظیمات ثبت شده باشد
   (`https://api.brsapi.ir/Market/Gold_Currency.php?key=...` — کلید رایگان)
۲. **نوبیتکس** — سرور ایران، ارز دیجیتال (بیت‌کوین، اتریوم، تتر)، بدون نیاز به کلید
   (`POST https://apiv2.nobitex.ir/market/stats`)
۳. **tala.ir** — سرور ایران، طلا و بخشی از سکه‌ها، بدون نیاز به کلید (`/ajax/price` —
   با اعتبارسنجی مقادیر؛ فید خراب سکه‌ی امامی/بهار نادیده گرفته می‌شود)
۴. **صفحه‌ی اصلی TGJU** — هاست خارجی، همه‌ی نمادها (پارس `<tr data-market-nameslug="...">`) +
   بیت‌کوین (به دلار، با نرخ دلار به تومان تبدیل می‌شود) و تتر
۵. **وب‌سرویس اسنیپت TGJU** — هاست خارجی، جایگزین نهایی (ارز و طلا و سکه)
۶. **کوین‌گکو** — هاست خارجی، بدون نیاز به کلید؛ فقط برای کریپتوهای جامانده و با
   تبدیل دلار به تومان (`/api/v3/simple/price?ids=bitcoin,ethereum,tether&...`)

```
https://www.tgju.org/
https://www.tala.ir/ajax/price
https://apiv2.nobitex.ir/market/stats
https://api.coingecko.com/api/v3/simple/price?ids=bitcoin,ethereum,tether&vs_currencies=usd
http://platform.tgju.org/fa/api/webservice-snippet/?token=webservice&items=...&opts=diff,time
```

قیمت‌های TGJU و نوبیتکس به **ریال** برمی‌گردند و در اپ به تومان تبدیل می‌شوند (÷۱۰)؛
بیت‌کوین TGJU و قیمت‌های کوین‌گکو به **دلار**‌اند و با نرخ لحظه‌ای دلار به تومان تبدیل می‌شوند؛
مقادیر tala.ir و BRS همین‌جا به تومان‌اند.
اگر هیچ منبعی در دسترس نباشد، آخرین قیمت‌های موفقِ ذخیره‌شده (حداکثر ۷ روز)
با برچسب «ذخیره‌شده» نمایش داده می‌شوند.

## بیلد

### با Android Studio
پروژه را باز کنید و Run بزنید. (minSdk 26)

### با GitHub Actions
هر پوش به شاخه‌ی `main` به‌صورت خودکار APK دیباگ می‌سازد؛
فایل را از تب Actions همان ران، بخش Artifacts با نام **Chandeh-debug-apk** دانلود کنید.

## ساختار پروژه

```
app/src/main/java/com/chandeh/app/
├── MainActivity.kt            # اکتیویتی اصلی + ناوبری پایین (قیمت‌ها / تبدیل)
├── data/
│   ├── Symbols.kt             # لیست نمادها و کدهای TGJU
│   ├── TgjuService.kt         # ثابت‌های منبع TGJU
│   ├── HttpClient.kt          # کلاینت HTTP مشترک (OkHttp)
│   ├── Prefs.kt               # کلیدهای SharedPreferences
│   ├── PriceCache.kt          # کش آخرین قیمت‌های موفق
│   └── PriceRepository.kt     # دریافت موازی چندمنبعی + ادغام + پارس پاسخ‌ها
├── ui/
│   ├── PricesViewModel.kt
│   ├── theme/Theme.kt         # تم تیره
│   └── screens/
│       ├── PriceListScreen.kt
│       └── ConverterScreen.kt
└── util/FaNumbers.kt          # اعداد فارسی و جداکننده‌ی هزارگان
```

## تغییرات نسخه‌ها

### ۱٫۰٫۱ (بیلد ۶)

- **ارز دیجیتال**: بیت‌کوین، اتریوم و تتر با بخش جدید «ارز دیجیتال» و قیمت به تومان
- **قیمت‌گذاری چندمنبعی کامل**: ۶ منبع موازی — نوبیتکس (سرور ایران، بدون کلید) و
  کوین‌گکو (خارجی) برای رمزارزها؛ بیت‌کوین و تترِ زنده‌ی TGJU هم اضافه شد
- اولویت‌بندی منابع داخلی برای همه‌ی نمادها (روی اینترنت ملی کامل‌تر کار می‌کند)
- مبدل ارز حالا رمزارزها را هم پوشش می‌دهد
